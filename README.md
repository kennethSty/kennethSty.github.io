# Kenneth Styppa — Personal homepage

A minimal static site designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Push these files to its `main` branch.
3. In **Settings → Pages**, set the source to **Deploy from a branch**, then select `main` and `/ (root)`.

The site will be available at `https://<your-github-username>.github.io`.
